## Bolt.new im Detail

Bolt.new ist eines der disruptivsten Tools der letzten Jahre. Es nutzt StackBlitz's WebContainer-Technologie — eine vollständige Node.js-Umgebung, die direkt im Browser läuft.

### Was Bolt.new kann

- **Frontend**: React, Vue, Svelte, Astro, Vanilla JS
- **Backend**: Node.js, Express, Supabase-Integration
- **Styling**: Tailwind CSS, shadcn/ui, CSS Modules
- **Deploy**: Ein Klick zu Netlify oder Vercel

### Typischer Workflow

1. "Erstelle eine Todo-App mit React und Tailwind" eingeben
2. Bolt generiert den kompletten Code
3. Live-Preview direkt im Browser
4. Änderungen per Chat-Prompt iterieren
5. Deploy mit einem Klick

Ideal für Prototypen, MVPs und Landing Pages.
