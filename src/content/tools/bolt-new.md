## Bolt.new in Detail

Bolt.new is one of the most disruptive tools of recent years. It uses StackBlitz's WebContainer technology — a complete Node.js environment that runs directly in the browser.

### What Bolt.new Can Do

- **Frontend**: React, Vue, Svelte, Astro, Vanilla JS
- **Backend**: Node.js, Express, Supabase integration
- **Styling**: Tailwind CSS, shadcn/ui, CSS Modules
- **Deploy**: One click to Netlify or Vercel

### Typical Workflow

1. Type "Create a Todo app with React and Tailwind"
2. Bolt generates the complete code
3. Live preview directly in the browser
4. Iterate changes via chat prompt
5. Deploy with one click

Ideal for prototypes, MVPs, and landing pages.
