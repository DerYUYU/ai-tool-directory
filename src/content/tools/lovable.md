## Lovable im Detail

Lovable (früher GPT Engineer) ist auf SaaS-Produkte spezialisiert. Es kombiniert Frontend-Generierung mit automatischer Supabase-Integration — du bekommst Auth, Datenbank und API komplett fertig.

| Feature | Lovable | Bolt.new |

| Backend | ✅ Supabase Auto | Manuell |
| Auth | ✅ Fertig | Manuell |
| Datenbank | ✅ PostgreSQL | Manuell |
| Flexibilität | Mittel | Hoch |
| GitHub-Sync | ✅ Ja | ✅ Ja |

Lovable ist ideal wenn du schnell eine SaaS-App mit Benutzerverwaltung brauchst.
