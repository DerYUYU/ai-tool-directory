Research Rabbit takes an unusual approach to literature research: instead of a classic search, the tool visualizes connections between papers. When you import a paper, Research Rabbit shows all the papers it cites, all the papers that cite it, and related works — as an interactive network.

This is particularly valuable for researchers because you discover important works that you would never have found in a normal search. The Zotero integration is a big plus: your own library can be connected directly, and newly discovered papers can be added with one click. The fact that the tool is completely free makes it a must-bookmark for every researcher.
